Slide 3 · Como embarcar

Validar unit economics. Aportar com teto de retorno.

Estratégia de Alocação em Fases: redução progressiva de risco com capital liberado conforme o atingimento de marcos operacionais. Participação na receita líquida com Return Cap 2,0×–2,5× (ou recompra).

Fase 1 · 30–45 dias

Piloto de canal

Entrada: R$ 2.500 – 4.900

  • Cobre setup, tráfego de teste e créditos de API
  • Cupom + oferta App base + 1 crédito
  • Adesão ≥ 25% dos atendidos
  • CAC · LTV (base + créditos 90d)
  • Custo API médio / user
  • Gate: LTV > 3× CAC e margem bruta > 0
Fase 2 · pós-prova

Aporte Seed (escalonado)

Liberado conforme performance do piloto

  • 100% da meta: R$ 29.000 → 20% da receita líquida*
  • 70–80% da meta: R$ 19.000 → 15% (proporcional)
  • < 70%: sem Seed — redesenho do piloto
  • Return Cap 2,0×–2,5× ou recompra
  • Após o cap: share encerra
Fase 3 · tração

Crescimento / Escala

R$ 49–79k → 25–30% · R$ 99k+ → 35–40%

  • Meta de volume (ex.: R$ 20k+/mês líquido)
  • Mesmo Cap 2,0×–2,5× por tranche
  • Capital para ads, estoque bureau, roadmap
  • % do projeto — não equity do CNPJ
